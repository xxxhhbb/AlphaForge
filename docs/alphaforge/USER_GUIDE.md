# AlphaForge 用户指南

## 1. 提出一个可研究的问题

好的问题至少包含研究对象、目标和约束。例如：

> 在大 A 市场中寻找预测未来 20 个交易日收益、与 50 日动量低相关，并在高低 Shibor 环境中稳定的 Alpha；比较估值、盈利质量、量价流动性和成本后效果。

不需要先指定统计模型。系统应保留用户目标，由研究组选择方法。

## 2. 阅读研究计划

计划页必须显示：

- 原始研究问题；
- research mode 和 subject；
- 研究深度与协作方式；
- 选中的专业研究组；
- 每组计划研究什么；
- 数据源、股票池、日期范围和可用性；
- 候选、Trial、模型调用预算；
- 检查点和停止条件；
- 当前限制或需要补数据的地方。

如果计划丢失目标期限、股票池或增量约束，不要确认，应修改问题或补充答案。

## 3. 显式确认

确认是研究开始前的产品边界，不是装饰按钮。确认后系统冻结计划身份。真实数据准备、网络访问和高成本运行应有单独清晰动作。

## 4. 运行与研究组

运行面板展示：

- `runId` 和 Campaign；
- 当前阶段；
- Provider/Model 的脱敏名称；
- 已选择研究组；
- 每组等待、运行、完成、部分、阻断、失败或取消状态；
- 候选数；
- 已用/总预算；
- typed failures；
- 取消和恢复操作。

未选择的研究组不应显示为失败。某一组数据不足时，其他独立组可以继续，依赖该组的下游任务必须阻断。

## 5. 合法终态

| UI 状态 | 含义 | 用户动作 |
| --- | --- | --- |
| 已完成 | 计划内研究与报告完成 | 阅读 Evidence 等级与限制 |
| 部分完成 | 有可用研究，但部分门禁/分支缺失 | 使用已完成部分，安排下一实验 |
| 已阻断 | 数据、能力、预算或安全门禁阻止继续 | 根据 failure code 补条件 |
| 失败 | 基础设施或不可恢复合同错误 | 保留运行 ID，排查并恢复 |
| 已取消 | 用户取消 | 可在支持时从检查点恢复 |

“已完成”是运行完成，不代表候选晋级。

## 6. 如何读报告

推荐阅读顺序：

1. 一句话结论；
2. 研究处置：继续验证、条件保留、拒绝、补数据或系统修复；
3. 最值得关注的发现；
4. 原问题回答到什么程度；
5. 证据等级；
6. 支持证据与反对证据；
7. 成本、稳定性、增量性或相关诊断；
8. 数据和方法限制；
9. 下一轮具体实验；
10. 展开机器指标和复现信息。

## 7. Evidence 等级

### 官方 Evidence

由独立确定性服务从冻结/PIT 合格数据重算。页面应明确显示“官方可见 Evidence”，但仍不等于 Promotion。

### 辅助研究

来自 Agent 生成表、Qlib、研究沙箱或动态资料。可以支持下一轮研究，但不能当作官方收益结论。最新三组专业报告即属于这一类。

### 无 Evidence / 数据缺口

没有足够输入、样本、时点语义或评价器时，报告应说明缺什么。空表、全 NaN、零方差或无事件 timing 不能显示为成功。

## 8. 研究深度

- 快速探索：适合确认数据和方向；不要期待完整 Evidence；
- 标准研究：适合多组实验和正式报告；
- 严格验证：要求更强复放、稳健性和独立门禁；仍不自动晋级。

## 9. 取消和恢复

取消应停止后续模型调用和实验，不删除已完成产物。恢复应复用相同 `runId`/计划身份，从首个未完成阶段继续。

如果恢复导致已完成研究组再次调用模型、重复 Trial 或重新消耗预算，应视为 bug 并保存运行 ID、时间和日志摘要。

## 10. 典型结果示例

### 正向但仅辅助

多个回归路线都发现换手率与未来收益正相关，但没有成本后回测。正确写法是“优先进入下一轮验证”，不是“换手率 Alpha 有效”。

### 负向结果

候选在样本外无稳定 IC 或成本后消失。正确产品结果是 `NEGATIVE_RESEARCH_RESULT`，保留证据和原因。

### 数据缺口

用户要求历史新闻事件，但只有当前抓取新闻且晚于决策窗口。正确结果是 `DATA_OR_CAPABILITY_GAP_REPORT` 或辅助研究，不回填历史。

### 系统失败

Manifest 损坏、Provider 持续不可用或 Runner 基础设施异常。只有这种情况才使用系统失败，并提供恢复游标。

## 11. 用户不应做的事

- 不把研究报告当交易指令；
- 不在问题中粘贴账户密钥或私有凭据；
- 不要求前端或 Agent 绕过数据/PIT/Evidence 门禁；
- 不用重试制造“直到显著”为止的免费搜索；
- 不根据隐藏 sealed 信息选择下一候选；
- 不把辅助研究截图剪掉标签后对外宣称官方结论。
